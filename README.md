# Velvet Bloom Fragrance House website UI

## Included
- `index.html`: self-contained responsive website UI with inline CSS and JavaScript.
- Mobile navigation, three product cards, brand story, numbered-batch selector, certificate preview, refill section, campaign journal, review placeholders, and newsletter preview.
- No build step or framework is required.

## Preview locally
Open `index.html` in a modern browser. Internet access is needed for Google Fonts and the sample Unsplash images. Replace these image URLs with approved Velvet Bloom product photography.

## Before launch
1. Confirm product sizes, descriptions, prices, stock and the actual limited-edition quantity.
2. Replace illustrative bottle art and stock imagery with approved product photography.
3. Connect each enquiry button to a real WhatsApp/contact/checkout route.
4. Connect newsletter signup to a consent-aware email marketing provider.
5. Replace review placeholders with genuine customer reviews used with permission.
6. Implement real inventory and certificate verification server-side. The current batch selector is only a visual demo and does not reserve, issue, or verify a bottle.
7. Connect Shopify or another commerce platform for secure checkout, taxes, shipping, order confirmation and privacy/returns policies.
8. Test on real Android/iOS devices, keyboard navigation, and slow connections.

## Brand direction
Burgundy, ivory, antique gold, elegant serif headings, restrained sans-serif labels, spacious editorial layout.
